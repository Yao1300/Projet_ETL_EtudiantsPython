# 📊 Pipeline ETL Data Analytics avec Python & SQL

## 📌 Description du projet

Ce projet met en œuvre un pipeline ETL complet permettant d'extraire, transformer, analyser et charger des données provenant de différentes sources.

L'objectif est d'automatiser le traitement des données afin de produire des informations fiables destinées à l'analyse décisionnelle et à la création de tableaux de bord.

Le projet reproduit une architecture professionnelle utilisée dans les environnements Data Engineering et Business Intelligence.

---

# 🎯 Objectifs

- Automatiser l'intégration des données.
- Nettoyer et transformer les données brutes.
- Effectuer des analyses statistiques et métier.
- Charger les données dans une base SQL.
- Produire des indicateurs KPI pour la prise de décision.
- Préparer les données pour Power BI.
